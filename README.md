# CondoGestor

Protótipo de gestão condominial servido como página estática pelo Vite.

## Executar

```sh
npm install
npm run dev
```

## Observação sobre os dados

Esta versão é a demonstração enviada e salva os dados no `localStorage` do navegador. Ela não sincroniza dados entre usuários nem usa o banco Supabase. O pagamento via Mercado Pago também aparece apenas como simulação no protótipo.
